## 5. 整体验收、决定和恢复入口

- 用户高风险决定：无 / 选项、影响、建议、决定及依据；已批准的常规迁移不重复请求许可
- 整体验收结论：未验证 / {对应第 2 节证据及所有必需任务状态}
- 当前整体状态：approved / implemented / verified（所有必需任务的验证与独立审查、整体验收均通过后才是 verified）
- 当前代码基线与未提交文件：待填写
- 下一步具体动作、负责人/窗口和停止点：待填写
- 未解决阻塞与失败历史：无 / {受影响任务、失败特征、已尝试修复、待决条件}
- 提交 / 合并 / 部署：分别填写“未做 / 已做及证据”

换窗口后先核对实际代码、已有改动和第 4 节证据；若证据失效或记录与事实不符，先修正记录和状态，再从下一步继续。待用户决定、失败历史和停止点不因换窗口消失。
