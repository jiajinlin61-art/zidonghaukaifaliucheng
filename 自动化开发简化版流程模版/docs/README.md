## 当前进度与下一步

- 当前步骤：接入 / 架构设计 / 等待架构“通过” / 基础架构 / 拆任务 / 开发 / 阶段验收
- 当前阶段、工作包 spec 与任务 ID：待填写
- 架构确认：未通过 / 已通过（版本、日期、用户消息位置）；未经明确通过不得开始基础架构代码

- 下一步具体动作与停止点：待填写

## 读取与恢复

首次接入先读根目录 `AGENTS.md`、本页、四份输入和项目现有代码。架构阶段读架构文档；基础架构阶段读获批架构、当前 spec 和 `docs/testing-mode.md`；拆任务后开发阶段再读计划与当前 spec。换窗口先核对代码、未提交改动、确认依据和验证证据；记录过时就修正，再从下一步继续。历史会话只能作为线索。
