# 需要人阅读的文档

首次了解或复制模板时阅读以下文件；处理后续需求时，助手只需读取项目规则、当前需求/状态和相关代码，不必每次重新加载整套说明：

1. [根目录使用说明](../README.md)：第一次使用工作流时阅读，包含复制模板、填写需求、启动开发和中断恢复方法。
2. [项目使用入口](../ai-development-workflow-v1/starter-project/README.md)：复制模板后阅读，说明新项目如何启动和恢复。
3. [项目规则](../ai-development-workflow-v1/starter-project/AGENTS.md)：了解助手必须遵守的范围、验证、人工审批和恢复规则。
4. [项目 Brief](../ai-development-workflow-v1/starter-project/docs/PROJECT_BRIEF.md)：由你填写，写清目标、范围、约束和成功标准。

## 按需阅读

- [工作流规则包说明](../ai-development-workflow-v1/README.md)：想了解 FAST、STANDARD、FULL 和详细材料时阅读。
- [开发流程](../ai-development-workflow-v1/DEVELOPMENT_WORKFLOW.md)：想了解任务、阶段和验收 Gate 的关系时阅读。
- `ai-development-workflow-v1/policies/`：只有需要调整人工审批、重试、质量门禁、上下文或 Git 规则时才阅读。
- `ai-development-workflow-v1/templates/`：明确启用完整规则包且项目需要对应文档时才填写；不要求一次性全部完成。只复制 starter 时不含完整包的 Router/Preflight 工具。

## 不需要日常阅读

- `.uads/plan.yaml` 和 `.uads/tasks/`：用于开发未来 UADS 程序的任务种子。
- `src/`、`tests/`、`tools/`、`.venv/`：开发和验证 UADS 本身使用。
- `SYSTEM_SPEC_V1_REV2.md`、`IMPLEMENTATION_PLAN.md`、`PHASE_0_START.md`、`docs/DEVELOPMENT.md`：只有要继续开发 UADS 自动执行程序时才阅读。

## 你实际需要做的事

复制模板，填写 `PROJECT_BRIEF.md`，然后把需求交给 AI 开发助手。助手会读取规则、创建必要计划、逐步实现并运行验证；你只需要在明确的人工检查点或业务取舍处作决定。
