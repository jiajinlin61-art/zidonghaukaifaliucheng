# Human Approval

授权按本次用户要求及已有有效授权判断。授权范围内的读取、分析、可逆编辑、测试、构建和文档更新通常可自动继续；质量 Gate 不等于重复人工许可。

但以下两类属于显式人工检查点，优先于一般自动继续规则：

1. Project Start / Plan Approval Gate：新项目命中 FULL、COMPLEX/CRITICAL、HIGH/CRITICAL risk、跨系统、架构变更，或用户明确要求先确认方案时，必须先展示开发计划并获得明确确认。用户说“自动开发/继续完成”不等价于批准尚未展示的复杂计划。FULL 项目在计划审批之外还需要第二次设计基线审批（PRD/原型/架构基线）才能开始功能代码；FAST/STANDARD 只使用一次按规模缩短的计划审批。
2. 尚未授权的删除/覆盖重要数据、生产发布、外部消息、付费资源、权限或凭据变更、破坏性迁移、公开接口/范围扩大，或无法合理推断的业务取舍。

Plan Approval Gate 未通过时，允许继续需求分析、架构、计划、只读环境检查和文档整理，但不得进入业务代码 Implementation。

用户明确批准后记录 approval_ref；沉默不构成批准。重启、换模型、换 Executor 或换 Session 不能清除待决人工检查点。仅暂停依赖答复的范围，其余不受阻塞的已授权分析工作可继续。
