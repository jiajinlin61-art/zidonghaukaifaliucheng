# 业务项目骨架

复制此目录（含隐藏的 .ai-dev）到业务项目，或向已有项目合并缺失内容。不要覆盖已有代码、规则或计划。

从 [AGENTS.md](AGENTS.md) 开始，写清当前需求或使用 [Brief](docs/PROJECT_BRIEF.md)。其它文件按 [.ai-dev/CONTEXT_INDEX.md](.ai-dev/CONTEXT_INDEX.md) 的触发条件读取，不必全部填写或每轮全部加载。

本骨架可独立使用，不携带完整规则包的 Python 工具。AGENTS.md 已预置共享路径及只读边界，但状态为“待接入”；首次使用须检查路径、版本和实际权限后明确启用。未经启用不宣称通过外部机器门禁。

完整使用教程位于共享根的 `docs/新项目接入完整流程使用教程.md`。业务记录写本项目；证据工具要求原始证据写入本项目专属、位于代码工作区和共享库之外的目录。复制模板不能自动改变 Codex/操作系统权限。

新功能先确认相称计划，FULL 再确认设计基线；已批准范围连续开发、验证、修复、独立审查和集成。交付真实可运行结果、启动方法和实际证据，说明未验证事项。
